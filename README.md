## NAME : MADHAN.S
## REG NO : 212223045004

## Aim:
To design a modern and user-friendly e-commerce mobile application named NovaMart using Figma. The application includes login, product browsing, product details, and shopping cart screens with a clean and attractive user interface.

## Algorithm:
1. Open Figma and create a new design file.
2. Set the mobile frame size to 393 × 852 pixels.
3. Choose a purple, white, and light lavender color theme.
4. Design the Login Screen with email, password, and login options.
5. Design the Home Screen with a search bar, product categories, offers, and recommendations.
6. Design the Product Details Screen with product images, price, ratings, and Add to Cart button.
7. Design the Shopping Cart Screen with selected products, quantity controls, order summary, and checkout button.
8. Add reusable components, icons, and typography.
9. Connect all four screens using Figma's Prototype feature.
10. Preview and test the application flow.
